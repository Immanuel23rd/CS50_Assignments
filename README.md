# Emmanuel - Personal Portfolio

Personal portfolio and CV for Emmanuel, a final-year Computer Networking student focused on networking, Linux, security, and full-stack development.

The site is a lightweight static build using HTML, CSS and JavaScript. It is designed for GitHub Pages.

## Focus

- Computer networking: TCP/IP, subnetting, VLANs, OSPF, BGP, NAT, ACLs, QoS, VPNs
- Linux and infrastructure: Ubuntu Server, Apache2, Nginx, Docker, Traefik, pfSense
- Development: Java, Maven, REST APIs, Spring Boot, Hibernate, React, PostgreSQL
- Security: Nmap, Lynis, Hydra, Suricata

## Deployment

GitHub Pages can publish this repository from the `main` branch. The connected GitHub tooling did not expose repository-creation or Pages-settings APIs, so the public repository `Immanuel23rd.github.io` is being used as the deployment target.
